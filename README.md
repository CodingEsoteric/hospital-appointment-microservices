# Hospital Appointment Microservices

**Course:** SEZG583 – Scalable Services  
**Assignment:** Assignment 1 – Design and Development of a Microservices Application

## Overview
A hospital appointment system built using four independently runnable microservices.

## Services
- **Appointment Service:** Booking lifecycle and idempotency.
- **Availability Service:** Doctor slots, capacity and reservations.
- **Patient Service:** Patient records and eligibility.
- **Notification Service:** Mock notifications and failure simulation.

## Technology Stack
- Java
- Spring Boot
- REST APIs over HTTP
- Separate database ownership per service
- OpenAPI/Swagger
- Automated unit and end-to-end tests

## Project Structure
Each microservice has its own application code, build configuration and database configuration.
